## 1. Scope

This SRS specifies the Bird Bend Stand: a pull/push (tension/compression) bend test stand made of a
NUCLEO-F446RE firmware (FW) that drives a horizontal ball-screw axis through a hybrid-servo stepper driver
(closed-loop mode, 4000 pulses/rev, D-27) and reads a load cell, and a Windows PC application (SW,
Python/PySide6) for configuration, manual control, calibration, tare, realtime display, test sequences and
reports. It covers system, safety, FW, interface, SW and non-functional requirements. The byte-level
protocol (`ICD_protocol.md`) and the parameter dictionary (`params.yaml`) are owned by the Integrator and
must implement the requirements here. The E-stop circuit (NC → MCU sense, NO → hardwired ENA cut; no power-removal contactor, CR-03:
D-41, D-42) and the 5 V buffer interface board are decided and documented in `01_HW/`.

## 2. Definitions

| Term | Definition |
|---|---|
| FS | Load-cell full scale: 200 kg = **1961.33 N** (G0 = 9.80665 m/s²). Nominal HX711 counts (3.0 mV/V, gain 128, ratiometric): **32 212 counts/kg**, 6 442 451 counts at FS; 1 % FS = 64 425 counts (R2 §4.4, ASSUMED nominal). |
| Raw counts | HX711 24-bit two's-complement result, sign-extended to int32, unscaled. Rail values 0x7FFFFF / 0x800000 (−8 388 608) = **saturated** (≈ 130 % FS). |
| Operational stop | IEC 60204-1 **stop category 2**: pulse generation ends, the driver stays **enabled and holding** (D-10 as amended by D-11). *Immediate* = no further step pulse after the stated reaction time; *controlled* = deceleration with `motion.a_stop_um_s2`, then stop (executed as a clean immediate halt only when the step period is > 2 ms and the stop distance is ≤ 1 step, D-29 (d), D-30). An operational stop never resumes the stopped move automatically. |
| E-stop | The **single red** NC mushroom button on the separate operator panel (with the PAUSE button; no separate physical holding STOP button, D-36). Its **NC contact** → MCU E-stop sense input (PA10): the FW stops pulses ≤ 100 µs, drives ENA to *disabled* ≤ 1 ms, latches ESTOP and clears HOMED (SAF-FW-005). Its additional **NO contact** drives the driver's ENA opto to *disabled* directly, independent of the MCU (hardwired ENA cut, D-42). There is **no power-removal contactor** (CR-03, D-41): the driver stays supplied; with ENA disabled the motor is de-energised and the load may back-drive the axis; position is lost ⇒ not homed. **Not an IEC 60204-1 emergency stop** (residual risk accepted by the PO, D-41; SYS-006, KL-08). |
| DRV_PWR | Optional MCU input (PA7) sensing the driver's 48 V supply: closed = driver powered (fixed fail-safe polarity). Disabled by default (`drv.pwr_sense_enable` = false since CR-03, D-41); while disabled, status DRV_PWR reads 1. |
| K1_WELDED | Latched fault: E-stop sense open while DRV_PWR still reports driver power for longer than `drv.k1_weld_ms` (default 200 ms). Meaningful only with the optional power sense enabled **and** a power-removal device that opens with the E-stop; none is fitted since CR-03 (D-29 (c), D-41, OI-18). |
| ALM start-block | Release-1 reaction to the driver ALM output: **new** motion commands are refused while ALM is active **and** driver power is present; running moves are not affected (D-28, extends D-16). Alarm reset = driver power cycle (48 V supply off/on). |
| STOP (GUI) | GUI STOP button: immediate operational stop, sequence terminated, not latched in FW (D-26 (2)). |
| HALT | Latched immediate operational stop raised by the PC **HALT** command (Pause/Break key); sequence terminated; cleared only by HALT_CLEAR (D-14, D-36). Not an E-stop. |
| PAUSE | Physical PAUSE button (MCU input, NO contact, operator panel) or GUI Pause (PC **PAUSE** command, same FW behaviour, D-29 (a)): controlled operational stop and FW latch **PAUSED**, which **blocks every new motion start** (MOVE_ABS, MOVE_UNTIL_LOAD, HOME, JOG ≠ 0 incl. refreshes of a running jog) (D-30); sequence **paused** and resumable (D-14, D-26 (1)). PAUSED is cleared only by the PC command **RESUME** (clears PAUSED only; refused while HALT, ESTOP or a fault is latched) or by HALT_CLEAR (clears HALT and PAUSED) (D-31); never by a motion command. |
| RESUME | PC command (GUI Resume, or the SW's reaction to the button's RESUME_REQUEST): clears PAUSED only; the SW then re-issues the interrupted step's absolute target (D-31). A clear never starts motion. |
| Homed | FW state: machine coordinate referenced by a completed HOME sequence and not invalidated since (E-stop, driver power loss, disable, idle disable, step fault, failed/aborted homing, reset). |
| Machine coordinate | Travel x [µm on the wire, mm in SW], 0 = home reference (`home.offset_um` from the START switch edge), increasing away from the home (START) switch. Release 1 homes at the START switch only (D-29 (b)). |
| Test travel zero | PC-side offset `x_zero` (e.g. at specimen contact); test travel = x − x_zero. Never sent to the FW. Sequence travel targets are relative to it by default (`x_zero` frozen at sequence start, D-29 (k)). |
| No-specimen mode | Session-only SW mode in which the operator has switched the SW load limits off after an explicit confirmation (first use / no calibration); a persistent banner is shown; the FW load limit stays at its nominal default (SW-LIM-004, D-29 (h)). |
| Active travel calibration | The steps/mm stored in the board NVM together with the SW file `active_travel.json`. A value written to the board RAM during the travel wizard is a trial value until the wizard result is accepted (SW-CAL-001). |
| Session parameter | Dictionary parameter with `nvm: false` (`safety.zero_raw`, `safety.load_raw_min/max`): written by the PC (SAF-SW-002), never stored in NVM; boot and DEFAULT_PARAMS set the default (D-29 (f), SD-05). |
| Latest-wins | SW rule for manual targets: while a move runs, a newer target replaces the pending one and is sent when the move completes (D-29 (i)). |
| Setpoint distance | D-05 field: commanded profile position = steps issued so far × 1000 / `steps_per_mm` [µm], latched at HX711 data-ready (R4 §2.3; interpretation ASSUMED, §10). |
| Validity flag (VALID) | DATA flag bit 0, set/reset by PC command (PO-FW-7); marks frames usable for analysis; FW clears it automatically on every stop/fault. |
| Moving / idle | Moving = FW is generating pulses or executing a ramp (MOVING flag). Idle = not moving. |
| Steady-state window | Report samples of a step: VALID = 1, MOVING = 0, setpoint distance constant, no stop/fault flag, t ∈ [t_reached + settle, t_reached + settle + capture] (R4 §8.3). |
| Tare | `tare_raw` = robust mean raw over the tare window; force F = K·(raw − tare_raw) (R4 §7). |
| Load calibration | K [N/count], B [N] from an OLS fit over zero + known weights (R4 §6). |
| Soft limits | FW travel limits [`limits.soft_min_um`, `limits.soft_max_um`] (machine coordinate), active when homed. **SW travel limits**: per-test limits inside them. |
| FW load limit | Raw thresholds `safety.load_raw_min/max` (session parameters) compared by the FW on every sample (D-12). **SW load limits**: force limits in N evaluated on the PC. |
| Latched | The condition persists until its stated clear condition is met. |
| Link capacity | 92 160 B/s (921 600 Bd, 8N1). |
| p95 | 95th percentile over ≥ 100 trials. |
| Reference PC | The PO's Windows 10 lab PC used with the stand (ASSUMED, §10); its spec is recorded in each performance test report. |
| Dead-man | Jog motion continues only while refreshed by the PC. |
