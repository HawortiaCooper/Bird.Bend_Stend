# 02_FW — NUCLEO-F446RE firmware (Implementer A)

Process: `00_System/PROCESS.md`. Design: `docs/FW_design.md` (**v0.7**: M1 notes §9.6, M2 §9.7–§9.9,
MOVE_UNTIL_LOAD + M3 fixes §9.10). Baseline: SRS v0.6.1, ICD v0.7.x (`src/gen/proto_gen.h` states the
exact version). Feature bits of the release image: AFE, MOTION, HOMING, MOVE_UNTIL_LOAD (D-44), NVM,
BUTTONS, DRV_SIGNALS.
D-06: never upload / open a COM port without the product owner's approval (`upload_protocol` is
declared only for completeness).

## Layout
| Path | Content |
|---|---|
| `src/gen/` | generated by the Integrator (`00_System/tools/gen_params.py`) — never edited here |
| `src/pure/` | pure C11 logic, no HAL (host-tested) |
| `src/core/` | application core, calls only the `src/hal/hal_*.h` seams (target and host twin) |
| `src/hal/hal_*.h` | seam v1.3 (= `00_System/tools/README.md`) |
| `src/hal/f446/` | NUCLEO-F446RE register-level implementation of the seams (+ `meas_f4.c`, measurement images only) |
| `include/` | pins, NVIC levels, FW constants |
| `ldscript/bend_f446re.ld` | sector 0 = vectors only, sectors 1+2 = NVM log (empty in the image), code from sector 3 |
| `tools/` | pre/post build scripts (build id + gen check, map check, vectors -> C headers, strict host flags) |
| `test/test_impl_*`, `test/common_impl/` | Implementer A host suites and fake seams (Validator E suites: `test/test_val_*`, `test/twin/`, `test/static/`) |

## Images (`platformio.ini`)
| Env | Purpose |
|---|---|
| `nucleo_f446re` | release image |
| `nucleo_f446re_meas`, `nucleo_f446re_meas_dwt` | HW-gate measurement images (DIAG_MEAS, + DWT statistics); core / pure objects identical to the release image |
| `nucleo_f446re_synth` | bring-up image with the synthetic AFE source (no HX711) |
| `nucleo_f446re_debug` | debug image (IWDG frozen while halted) |

## Commands (PowerShell, repo root)
Several roles build concurrently: always give each run a private build directory, otherwise parallel
runs corrupt `02_FW/.pio/build` (Windows errors 32 / 2 / 193).
```powershell
$env:PLATFORMIO_BUILD_DIR = "<your scratchpad>\pio_build"   # private build dir (required)
. 02_FW\tools\host_env.ps1                                     # CLion MinGW GCC 13.1 on PATH
.venv\Scripts\pio test -d 02_FW -e native -f "test_impl_*"     # Implementer A host suites (vectors in place)
# unfiltered `-e native` also runs Validator E's test_val_* suites: run E's gen_val_vectors.py first
# (they need 02_FW/.pio/val_vectors/; a missing file is a FAIL, OBS-M1-04)
.venv\Scripts\pio run  -d 02_FW -e nucleo_f446re               # release image + sizes + tools/check_map.py
.venv\Scripts\pio run  -d 02_FW -e nucleo_f446re_meas          # likewise for the other images
```

## Host twin (Integrator)
`00_System/tools/fw_twin/build.py --core fw --build-dir <private dir>` compiles `src/pure`, `src/gen`,
`src/core` unchanged with the twin implementation of every `hal_*.h` seam and
`-DFW_FEATURE_EXTRA=FEAT_TWIN`. Entry points: `app_init()`, `app_loop()` (main-loop pass),
`core_tick_1ms()` (every 1000 µs), `on_afe_sample()` (sample callback, level 3), `step_isr()` (step
timer update, level 2), `on_input_edge()` (input EXTI after the HAL fixed reaction, levels 0/1).
Validator E's twin suites: `VAL_TWIN_BUILD_DIR=<private dir>` then `pytest 02_FW\test\twin`.
