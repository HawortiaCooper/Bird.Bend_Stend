# 02_FW — NUCLEO-F446RE firmware (Implementer A)

Process: `00_System/PROCESS.md`. Design: `docs/FW_design.md` (v0.4; M1 notes in §9.6).
D-06: never upload / open a COM port without the product owner's approval (`upload_protocol` is
declared only for completeness).

## Layout
| Path | Content |
|---|---|
| `src/gen/` | generated by the Integrator (`00_System/tools/gen_params.py`) — never edited here |
| `src/pure/` | pure C11 logic, no HAL (host-tested) |
| `src/core/` | application core, calls only the `src/hal/hal_*.h` seams (target and host twin) |
| `src/hal/hal_*.h` | seam v1.1 (= `00_System/tools/README.md`) |
| `src/hal/f446/` | NUCLEO-F446RE register-level implementation of the seams |
| `include/` | pins, NVIC levels, FW constants |
| `ldscript/bend_f446re.ld` | sector 0 = vectors only, sectors 1+2 = NVM log (empty in the image), code from sector 3 |
| `tools/` | pre/post build scripts (build id + gen check, map check, vectors -> C headers, strict host flags) |
| `test/test_impl_*`, `test/common_impl/` | Implementer A host suites and fake seams (Validator E suites: `test/test_val_*`) |

## Commands (PowerShell, repo root)
```powershell
. 02_FW\tools\host_env.ps1                         # CLion MinGW GCC 13.1 on PATH
.venv\Scripts\pio test -d 02_FW -e native          # host suites (vectors read in place, gate on ICD/hash)
.venv\Scripts\pio run  -d 02_FW -e nucleo_f446re   # release image + sizes + tools/check_map.py
.venv\Scripts\pio run  -d 02_FW -e nucleo_f446re_debug
```

## Host twin (Integrator)
Compile `src/pure`, `src/gen`, `src/core` with the twin implementation of every `hal_*.h` function the
core calls (reference: `test/common_impl/fake_hal.c`) and `-DFW_FEATURE_EXTRA=FEAT_TWIN`; include
paths `include src src/pure src/gen src/core src/hal`. Entry points: `app_init()`, `app_loop()` (main
loop pass), `core_tick_1ms()` (every 1000 µs), `on_afe_sample()` (sample callback);
`step_isr()` / `on_input_edge()` are M1 stubs.
